# Sumber foto kategori (nonproduk individual)

Foto ilustrasi ditemukan melalui pencarian web, bukan hasil unggahan pemilik toko. Hanya tautan Wikimedia Commons yang menurut halaman file memiliki status **CC0 atau domain publik** yang dipilih. Foto diambil langsung sebagai URL gambar (hotlink), bukan file lokal yang direproduksi. Sebelum penggunaan komersial, tinjau ulang status file bila ada perubahan dan gantikan dengan foto asli toko ketika tersedia.
